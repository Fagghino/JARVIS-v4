01

Titolare del Trattamento

Il titolare del trattamento dei dati per il bot Discord J.A.R.V.I.S. (in seguito denominato "Bot") e per la relativa piattaforma web raggiungibile su https://jarvis-v5-cto5.onrender.com (in seguito "Web Dashboard") è lo sviluppatore Fagghino e il team di manutenzione di J.A.R.V.I.S.

La presente informativa si applica a qualsiasi utente interagisca con il Bot all'interno di un server Discord in cui esso sia presente, nonché a chiunque effettui l'accesso alla Web Dashboard tramite il protocollo Discord OAuth2.

02

Tipologia di Dati Raccolti

J.A.R.V.I.S. adotta rigorosamente il principio di minimizzazione dei dati (Art. 5 GDPR), trattando esclusivamente i parametri tecnici indispensabili all'erogazione delle sue funzionalità di gamification, utilità e configurazione:

Categoria Dati Trattati Scopo di Utilizzo
Identificativi Discord User ID univoco, Server (Guild) ID, Channel ID, Username e Discriminatore. Identificazione del profilo all'interno del server per l'esecuzione dei comandi slash e gestione dei permessi.
Gamification & Livelli Punti XP totali accumulati, livello raggiunto, conteggio messaggi e tempo di permanenza nei canali vocali. Calcolo del livello, assegnazione di ruoli automatici, generazione della card profilo /rank e compilazione della classifica pubblica del server.
Configurazioni del Server Canali di benvenuto/addio, canali vocali contatori, ruoli autorizzati, testi personalizzati e toggle di funzionalità. Memorizzazione permanente delle preferenze di funzionamento stabilite dagli amministratori del server.
Sessione Web Dashboard Discord User ID, username, avatar hash e lista identificativi dei server in cui si possiede il permesso di Amministratore. Autenticazione sicura tramite OAuth2 per consentire l'accesso al pannello di gestione dei soli server autorizzati.
03

Dati che NON Vengono MAI Raccolti

Per la massima trasparenza e tranquillità della tua community, specifichiamo chiaramente cosa non entra mai nei nostri database:

  • Nessun messaggio privato (DM): il bot non legge, non analizza e non memorizza le conversazioni private tra utenti.
  • Nessun archivio dei testi di chat: il bot ascolta i messaggi solo per calcolare gli XP o attivare comandi con prefisso legacy; il testo effettivo della chat non viene salvato sui nostri server né ceduto a terzi.
  • Nessuna credenziale, password o token: le password del tuo account Discord o le credenziali personali non sono mai accessibili dal Bot né dalla Dashboard.
  • Nessun dato finanziario o di pagamento: il bot è interamente gratuito e non raccoglie numeri di carte, coordinate bancarie o dettagli di fatturazione.
💡 Protezione delle conversazioni: I contenuti dei messaggi degli utenti non vengono mai registrati nel nostro database. Viene incrementato unicamente il contatore numerico dei punti esperienza e dei messaggi per la classifica.
04

Finalità del Trattamento

I dati raccolti vengono utilizzati unicamente per:

  • Garantire il corretto funzionamento dei comandi (es. /rank, /classifica, /serverinfo, /traduci).
  • Aggiornare i contatori dei canali vocali (membri totali, utenti online, bot presenti).
  • Inviare notifiche di benvenuto, addio o avanzamento di livello configurate dai gestori del server.
  • Consentire agli amministratori del server di personalizzare i moduli e monitorare le statistiche aggregate tramite Web Dashboard.
  • Proteggere l'infrastruttura contro attacchi DoS, abusi dei comandi o tentativi di exploit tramite cooldown e sistemi di alert Sentinel.
05

Base Giuridica del Trattamento

Il trattamento dei dati si fonda su:

  • Esecuzione di un servizio richiesto (Art. 6.1.b GDPR): l'utente o il proprietario del server installa il bot o interagisce con i comandi, richiedendo implicitamente l'erogazione delle relative risposte.
  • Legittimo interesse (Art. 6.1.f GDPR): la necessità tecnica di preservare l'integrità del servizio, mitigare attacchi spam e garantire la stabilità dell'infrastruttura.
06

Conservazione e Misure di Sicurezza

I dati vengono salvati in un cluster cloud MongoDB Atlas protetto, situato in datacenter europei conformi a ISO 27001 e SOC 2, con crittografia end-to-end sia a riposo (Encryption-at-Rest) che in transito (TLS/SSL).

I dati non vengono venduti, affittati né ceduti a intermediari pubblicitari, broker di dati o terze parti per scopi di marketing. L'accesso al database è strettamente limitato all'istanza operativa del bot tramite credenziali segrete protette da variabili d'ambiente isolate.

07

I Tuoi Diritti e Cancellazione dei Dati (Diritto all'Oblio)

In conformità agli articoli 15-22 del Regolamento GDPR e alle policy per gli sviluppatori di Discord, ogni utente e amministratore ha il diritto di:

  • Accedere ai propri dati: visualizzare in qualunque momento i propri punti XP tramite il comando /rank o consultando la classifica web /leaderboard/:guildId.
  • Richiedere la rettifica o l'aggiornamento: correggere configurazioni errate tramite la Web Dashboard o richiedere l'azzeramento di statistiche errate.
  • Richiedere la Cancellazione Totale (Diritto all'Oblio): richiedere l'eliminazione completa e definitiva del proprio record XP o della configurazione del server dai nostri database.
🗑️ Come richiedere la cancellazione: È sufficiente inviare un'email all'indirizzo del supporto o contattare lo sviluppatore sul server Discord ufficiale specificando il proprio Discord User ID o il Server ID. I dati associati verranno rimossi permanentemente entro 48 ore lavorative.
08

Servizi di Terze Parti Coinvolti

Per il funzionamento complessivo dell'applicazione, J.A.R.V.I.S. si appoggia ai seguenti fornitori di infrastruttura:

  • Discord Inc.: piattaforma di hosting del bot e fornitore del protocollo di autenticazione OAuth2 (Informativa Privacy Discord).
  • Render Services Inc.: piattaforma di hosting cloud in cui risiede l'istanza Node.js del bot e della Web Dashboard (Informativa Privacy Render).
  • MongoDB Atlas: infrastruttura di database NoSQL cloud ad elevata sicurezza (Informativa Privacy MongoDB).
